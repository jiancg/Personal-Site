# Personal Site

A responsive portfolio site featuring a real‑time Spotify stats built with React, Express, Tailwind CSS, and REST APIs.

## Tech Stack

- [React](https://react.dev/)
- [Material UI](https://mui.com/material-ui/) v12.4.0
- [Tailwind]()
- [Vite](https://vite.dev/)
- [Node-Fetch](https://www.npmjs.com/package/node-fetch)

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/jiancg/Personal-Site.git
cd Personal-Site
```

### 2. Install dependecies

```bash
npm install
```

### 3. Start The Development Server

```bash
npm run dev
```
